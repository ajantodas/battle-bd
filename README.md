# Battle BD - Multiplayer

## Run on your laptop
    npm install
    npm start
Open http://localhost:3000. Friends on the same Wi-Fi can open http://YOUR-LAPTOP-IP:3000.

## Host online (Render, free)
1. Push this folder to a GitHub repository.
2. On render.com: New > Web Service > select the repository.
3. Build Command: npm install    Start Command: npm start    Plan: Free
4. When deployed, open the https://....onrender.com link. Everyone enters the same room code and presses JOIN GAME. The host presses START GAME.

The free plan sleeps when idle, so the first load can take about a minute.

## Rules
Up to 8 players per room. The zone shrinks and the last player alive wins.

## Controls
PC: WASD move, Shift sprint, Space jump, mouse aim, click shoot, R reload, M sound on/off.
Phone: left side joystick, drag right side to look, FIRE / JUMP / RELOAD buttons, speaker button for sound.
